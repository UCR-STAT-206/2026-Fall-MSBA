Homework 3

Due 10am on October 22, 2026

Instructions

  1. You should implement your solution using a Python module. Call it pricing.py and load it with import pricing.
  2. The sample code provided to you is for you to check your solution. You are responsible for creating any variables required in carrying out the tests.
  3. for loops and while loops are forbidden for this assignment.
  4. Think in terms of a system. You should write functions to handle discrete tasks and combine them to solve the larger task at hand.

Deliverables

  • A Python source file named pricing.py, as described.
  • A Quarto source file named testing.qmd, illustrating that illustrates how to use your module and passes all checks.

Overview

You’re tasked with implementing a pricing module for an e-commerce retailer. This module must handle the following tasks:

  • Data cleaning
    • The system recording the number of units ordered randomly flipped the signs of some quantities, making these numbers negative.
    • Some price information may have also been lost, resulting in zero values.
  • Apply discounts and compute total revenue
    • Raw totals are computed as \(\text{raw total} = \text{units} \times \text{unit price}\).
    • Any orders over 10 units automatically receive a 5% volume discount.
    • The total revenue must therefore factor in the volume discount applied to some of the orders.
  • Compute final order totals
    • Orders are purchased from different states subject to different sales tax rates.
    • Using a simple lookup table, you must calculate the tax amount on each order.
    • Combine discounted totals with tax amounts to obtain the final order totals.

You’ve been given sample data to test your pricing module, namely the files hw3_raw_order_data.txt and hw3_raw_order_state_ids.txt. In addition, you’ll need the following integer codes corresponding to different states and their tax rates:

Code State Sales Tax Rate
0 California (CA) 7.25%
1 Texas (TX) 6.25%
2 Oregon (OR) 0.00%
3 New York (NY) 8.00%
4 Florida (FL) 6.00%
