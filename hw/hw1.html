Instructions

  1. Your work should be in the form of a Quarto file named hw1.qmd. Python code should appear in code chunks.
  2. You are responsible for ensuring your work is reproducible on someone else’s computer. That means:
    • Verifying that hw1.qmd renders properly as an HTML report.

Problem 2

The following small Python programs store values in variables and use the print() function to produce an output. Treat each code block as a self-contained unit, meaning the code in the first code block has no influence on any subsequent code blocks.

Tracing the flow of a program

In each case, determine what each program outputs.

nephew = 'Jack'
print(nephew)
nephew = 'Jack'
print('nephew')
nephew = 'Jack'
nephew = 'Albert'
print(nephew)
nephew = 'Jack'
Nephew = 'Albert'
print(nephew)

Reasoning about errors

The following programs will produce errors in a fresh Python session. In each case, explain why each self-contained block produces an error.

TipHint

To produce the errors yourself, start a fresh Python session in a terminal, copy a code block, and paste it into your Python session. Do this for each example to make the code self-contained.

Problem 3

In this exercise you’re going to write some code to help you cook a brilliant lasagna from your favorite cooking book. You have four tasks, all related to the time spent cooking the lasagna.

1. Store the expected bake time in a constant

Define the expected_bake_time constant that returns how many minutes the lasagna should bake in the oven. According to the cooking book, lasagna needs to be in the oven for a total of 60 minutes.

2. Calculate the preparation time in minutes

Define the preparation_time function that takes the number of layers you added to the lasagna as an argument and returns how many minutes you spent preparing the lasagna, assuming each layer takes you 2 minutes to prepare.

3. Calculate the remaining oven time in minutes

Define the remaining_time function that takes the actual minutes the lasagna has been in the oven as a parameter and returns how many minutes the lasagna still has to remain in the oven.

4. Calculate the total working time in minutes

Define the total_working_time function that takes two arguments: the first argument is the number of layers you added to the lasagna, and the second argument is the number of minutes the lasagna has been in the oven. The function should return how many minutes in total you’ve worked on cooking the lasagna, which is the sum of the preparation time in minutes, and the time in minutes the lasagna has spent in the oven at the moment.
