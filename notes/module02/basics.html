The future value of a financial instrument under compound interest is

\[ \text{FV} = \text{PV} \times (1 + r)^{n}, \]

where \(r\) is the rate of return and \(n\) denotes the number of periods. We can use Python to do this calculation:

pv = 100.0 # one lump-sum investment
r = 0.07   # annual rate
n = 10     # 10 years

fv = pv * (1 + r) ** n

Boolean algebra provides a mechanism to combine logical statements. Comparisons on data types allow us to check various conditions. This functionality will become important later in using conditional code.

5 > 4
True
5 >= 5
True

As an example application, suppose you run an e-commerce business and want to extend a promotion to certain customers. You have a few requirements:

  • The customer should NOT be blacklisted by your business.
  • For free shipping: The customer meets a minimum spend threshold AND is known to be a repeat customer.
  • For an extra discount: The customer is a repeat customer OR is already using a coupon.

These checks can be implemented using comparison + Boolean operators.

# data
is_blacklisted = False
is_loyalty_member = True
order_total = 74.89
has_coupon = False

# checks
is_safe_customer = not is_blacklisted
qualifies_for_shipping = order_total >= 75 and is_loyalty_member
qualifies_for_discount = is_loyalty_member or has_coupon
final_approval = is_safe_customer and (qualifies_for_shipping or qualifies_for_discount)
print(f"Is this a safe customer? {is_safe_customer}")
print(f"Do they qualify for free shipping? {qualifies_for_shipping}")
print(f"Do they qualify for a discount? {qualifies_for_discount}")
print(f"Do they receive the promotional offer? {final_approval}")
Is this a safe customer? True
Do they qualify for free shipping? False
Do they qualify for a discount? True
Do they receive the promotional offer? True

Notions of Equality

Python distinguishes between two notions of equality.

x = [1, 2, 3] # this is a list
y = [1, 2, 3] # also a list

The == operator is for equality in value:

x == y
True

The is operator is for exact equality (meaning a computer cannot distinguish these two objects):

x is y
False

The reason the last example is False is that x and y are bound to different instances of a list object. The two objects therefore differ in how they are stored in memory.

In contrast, the same comparisons all evaluate to True in the following example.

x = 1
y = 1
x == y
True
x is y
True

The reason is that int objects are completely determined by their bits, so it is impossible for Python to distinguish that 1 from that other 1.
