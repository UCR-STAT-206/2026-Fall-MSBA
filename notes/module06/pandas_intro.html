Pandas Introduction

Goals

  1. Understand what pandas is for and when to reach for it.
  2. Load a CSV file of tabular data into a Python session.
  3. Meet the two core objects: the Series (one column) and the DataFrame (a full table).
  4. Inspect a table using its attributes and a few summary methods.
  5. Answer basic analytics questions with the following operations: selecting columns, sorting, filtering, and creating new columns.

Overview

  • pandas is a Python library for data analysis and manipulation.
  • It is built for tabular data: rows and columns, just like a spreadsheet or a database table.
  • It is the standard tool for this job in Python, so nearly every data analytics workflow you meet will use it.

pandas has two main objects.

Name Dimensions Description
Series 1 One labeled column of values, all of the same type
DataFrame 2 A labeled table made up of several columns

What can pandas do?

The library is huge. For now, we only need a small corner of it:

  • Reading and writing files (CSV, Excel, and more).
  • Looking at, sorting, and filtering tables.
  • Creating new columns from existing ones.

Getting Started

We must import the package like any other Python package.

import os
import pandas as pd

By convention, pandas is imported under the nickname pd. Nearly all tutorials, books, and Stack Overflow answers do the same, so you should too.

TipWhere to learn more

The official Getting Started guide and User Guide are good references. You are not expected to memorize functions; part of working with pandas is looking things up.

Loading your first dataset

Suppose you have an advertising dataset: for each of 200 markets, the amount spent on TV, radio, and newspaper advertising (in thousands of dollars) and the resulting product sales (in thousands of units). It is stored as a CSV file (Comma-Separated Values), which is just plain text:

,TV,radio,newspaper,sales
1,230.1,37.8,69.2,22.1
2,44.5,39.3,45.1,10.4
3,17.2,45.9,69.3,9.3
4,151.5,41.3,58.5,18.5
  • The first line holds the column names.
  • Each following line is one row of data, with values separated by commas.
  • The first column has no name; it holds row numbers (1, 2, 3, …).

We load it with pd.read_csv:

# Replace with the real path to the file on your computer or Colab session
ad_data = pd.read_csv(
    os.path.join("assets", "ISLP_Advertising.csv"),
    index_col=0
)

A few things to notice:

  • os.path.join(...) builds a file path that works on any operating system.
  • index_col=0 says “use the first column (the row numbers) as the row labels instead of as ordinary data.”

This dataset comes from Chapter 2 of An Introduction to Statistical Learning with Python (ISLP).

  • Each row is one market.
  • Each column is one variable (TV spend, radio spend, and so on).

More on the index

Every pandas object has an internal index, which is an immutable, 1D sequence used to store axis labels. This is how we can distinguish records from each other, even if they happen to contain the same values across every column.

  • Not every data file you work with will have an internal index. In such cases, pandas will create row labels automatically.
  • There is no need for index to be numbers.
  • If your dataset contains a column that can serve as a unique identifier, you can specify it with index_col when loading data.

Other ways to read and write data

pandas can read from and write to many formats. The most common pairs are:

  • pd.read_csv / .to_csv
  • pd.read_excel / .to_excel
  • pd.read_sql / .to_sql

For example, ad_data.to_csv("my_copy.csv") saves a table back to a file.

pandas can even read CSV text straight from a Python string if we wrap it in a StringIO object. This is handy for small examples:

from io import StringIO

Series vs DataFrame

  • A DataFrame is a full table (like a whole Excel sheet).
  • A Series is a single column of that table (like the sales column).

The Series

A Series has two parts: the values and an index (the labels for each value).

# Think of this as last week's daily website visits
visits = pd.Series(
    [120, 135, 150, 145, 160, 170, 190],
    index=["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]
)

visits
Mon    120
Tue    135
Wed    150
Thu    145
Fri    160

dtype: int64
  • First input: a list of values.
  • Second input: the labels, given through the named argument index.
  • Bottom line of the output: dtype is the data type of the values (here int64, whole numbers). A Series holds one data type.

We can pull out its parts and compute with it:

The DataFrame

A DataFrame is a collection of Series that share the same row labels. It has:

  • an index (row labels),
  • columns (column names), and
  • values (the data).

Attributes of a DataFrame

Attributes are pieces of information stored on an object. Unlike methods, they are written without parentheses.

ad_data.shape      # (number of rows, number of columns)
(200, 4)
ad_data.columns    # column names
Index(['TV', 'radio', 'newspaper', 'sales'], dtype='str')
ad_data.index      # row labels
RangeIndex(start=1, stop=201, step=1)
ad_data.dtypes     # data type of each column
TV           float64
radio        float64
newspaper    float64
sales        float64
dtype: object
ad_data.size       # total number of cells (rows x columns)
800
NoteAttribute vs. method

ad_data.shape is an attribute (no parentheses). ad_data.head() is a method, i.e. a function attached to the object, so it needs parentheses. If you forget the parentheses on a method, Python shows you the method itself rather than running it.

Creating new columns

We often derive new measures, like “total marketing spend.” Assign to a new column name; the arithmetic happens row by row.

ad_data["total_spend"] = ad_data["TV"] + ad_data["radio"] + ad_data["newspaper"]
ad_data[["TV", "radio", "newspaper", "total_spend"]].head()
TV radio newspaper total_spend

2 44.5 39.3 45.1 128.9
3 17.2 45.9 69.3 132.4

ad_data["sales_per_spend"] = ad_data["sales"] / ad_data["total_spend"]
