Vectorization and Broadcasting

Goals

  1. Understand what vectorization is and why it makes code both shorter and faster.
  2. Use element-wise arithmetic, comparisons, and NumPy’s mathematical functions on whole arrays at once.
  3. Understand the basic rules of broadcasting, which let arrays of different shapes work together.
  4. Replace simple for loops and if statements with vectorized equivalents.

What is vectorization?

Vectorization involves applying an operation to an entire array at once, rather than writing a loop that handles one element at a time.

You have already seen this idea: when x and y are NumPy arrays, x + y adds them element by element. In this section we look at why this matters and how far the idea extends.

import numpy as np

Suppose we have the unit price and quantity sold for five products, and we want revenue for each. Here is the approach you might write using only base Python:

prices = [4.50, 12.00, 3.25, 8.75, 20.00]
quantities = [100, 40, 250, 60, 15]

revenue = []
for p, q in zip(prices, quantities):
    revenue.append(p * q)
revenue
[450.0, 480.0, 812.5, 525.0, 300.0]

The vectorized version with NumPy:

prices = np.array([4.50, 12.00, 3.25, 8.75, 20.00])
quantities = np.array([100, 40, 250, 60, 15])

revenue = prices * quantities
revenue
array([450. , 480. , 812.5, 525. , 300. ])

The second version is shorter, closer to how we would write the math (\(\text{revenue}_i = p_i \times q_i\)), and has fewer places for bugs to hide.

Why is it faster?

A Python for loop has overhead on every iteration: Python checks types, looks up the operation, and creates new objects. NumPy instead hands the entire array to compiled code that implements repeated evaluation, which is far more efficient. Recall that this is possible because arrays are homogeneous: every element has the same dtype, so NumPy does not need to check each one.

Let’s compare the two approaches on a million numbers. The %%timeit magic command is available in IPython and runs a cell several times to measure how long it takes.

import time

n = 1_000_000
a = np.random.rand(n)
b = np.random.rand(n)

# loop version
start = time.perf_counter()
out = np.empty(n)
for i in range(n):
    out[i] = a[i] * b[i]
loop_time = time.perf_counter() - start

# vectorized version
start = time.perf_counter()
out = a * b
vec_time = time.perf_counter() - start

print(f"loop:       {loop_time:.4f} seconds")
print(f"vectorized: {vec_time:.4f} seconds")
loop:       0.1347 seconds
vectorized: 0.0013 seconds

The exact numbers depend on your computer, but the vectorized version is typically at least an order of magnitude faster. For small data the difference is practically invisible. The efficiency of your code becomes woefully noticeable once you start working with thousands or millions of rows.

NoteRule of Thumb

If you find yourself writing a for loop over the elements of a NumPy array, stop and ask whether there is a vectorized way to do it.

Arithmetic

All the usual arithmetic operators work element by element.

x = np.array([1.0, 2.0, 3.0, 4.0])
y = np.array([10.0, 20.0, 30.0, 40.0])
x + y
array([11., 22., 33., 44.])
x * y
array([ 10.,  40.,  90., 160.])
y / x
array([10., 10., 10., 10.])
x ** 2
array([ 1.,  4.,  9., 16.])

Operations between an array and a single number (a scalar) apply the scalar to every element. For example, to convert a list of prices to include a 10% markup:

prices * 1.10
array([ 4.95 , 13.2  ,  3.575,  9.625, 22.   ])

or convert a series of temperatures in Fahrenheit to Celsius:

temps_f = np.array([32, 50, 68, 86, 104])
(temps_f - 32) * 5 / 9
array([ 0., 10., 20., 30., 40.])

Mathematical functions

NumPy provides vectorized versions of the common mathematical functions. These are sometimes called universal functions, or ufuncs, because they work element by element on any array.

x = np.array([1, 4, 9, 16, 25])
np.sqrt(x)
array([1., 2., 3., 4., 5.])
np.log(x)
array([0.        , 1.38629436, 2.19722458, 2.77258872, 3.21887582])
np.exp(np.array([0, 1, 2]))
array([1.        , 2.71828183, 7.3890561 ])

Other commonly used functions include np.abs, np.sin, np.cos, np.round, np.floor, and np.ceil.

WarningUse NumPy’s functions, not math’s

Functions in Python’s math module only work on single numbers. Calling math.sqrt(x) on an array raises an error. Use np.sqrt(x) instead.

import math
math.sqrt(np.array([1, 4, 9]))
---------------------------------------------------------------------------
TypeError                                 Traceback (most recent call last)
Cell In[15], line 2
      1 import math
----> 2 math.sqrt(np.array([1, 4, 9]))

TypeError: only 0-dimensional arrays can be converted to Python scalars

Example: Asset log returns

The log return between consecutive prices is \(\log(P_t / P_{t-1})\). Given a series of daily closing prices, we can calculate all the returns at once by comparing the array against a shifted version of itself.

closing = np.array([100.0, 102.0, 101.0, 105.0, 107.0])
np.log(closing[1:] / closing[:-1])
array([ 0.01980263, -0.0098523 ,  0.03883983,  0.01886848])

Here closing[1:] is days 2 through 5 and closing[:-1] is days 1 through 4, so each division compares a day to the previous day.

Comparisons and logical operations

Comparison operators are also vectorized by default, returning an array of bool values. This is essential in building masks.

sales = np.array([120, 85, 240, 190, 60, 310])
sales > 100
array([ True, False,  True,  True, False,  True])

To combine conditions, use & (and), | (or), and ~ (not). Note that you must use these symbols, not the words and, or, not, and each condition needs its own parentheses.

(sales > 100) & (sales < 250)
array([ True, False,  True,  True, False, False])
(sales < 80) | (sales > 300)
array([False, False, False, False,  True,  True])
(sales > 100) and (sales < 250)
---------------------------------------------------------------------------
ValueError                                Traceback (most recent call last)
Cell In[20], line 1
----> 1 (sales > 100) and (sales < 250)

ValueError: The truth value of an array with more than one element is ambiguous. Use a.any() or a.all()

Since True counts as 1 and False counts as 0, you can count or average a mask directly:

(sales > 100).sum()   # how many values exceed 100?
np.int64(4)
(sales > 100).mean()  # what fraction exceed 100?
np.float64(0.6666666666666666)

Vectorized if-else with np.where

What if you want to replace an if/else inside a loop? Use np.where(condition, value_if_true, value_if_false).

# label each day's sales as "high" or "low"
np.where(sales > 150, "high", "low")
array(['low', 'low', 'high', 'high', 'low', 'high'], dtype='<U4')

It works with numbers too. Suppose orders over $200 get a 5% discount and everything else is full price:

np.where(sales > 200, sales * 0.95, sales)
array([120. ,  85. , 228. , 190. ,  60. , 294.5])

Summaries along an axis

Aggregation methods like .sum(), .mean(), .min(), .max(), and .std() are also vectorized. For 2D arrays, the axis argument controls the direction of the calculation.

# rows = stores, columns = months
revenue = np.array([
    [10, 12, 15],
    [20, 18, 25],
    [ 8,  9, 11],
    [30, 28, 35]
])
revenue
array([[10, 12, 15],
       [20, 18, 25],
       [ 8,  9, 11],
       [30, 28, 35]])
revenue.sum(axis=0)  # collapse the rows: total for each month
array([68, 67, 86])
revenue.sum(axis=1)  # collapse the columns: total for each store
array([37, 63, 28, 93])

A helpful way to remember: axis=0 means “go down the rows,” and axis=1 means “go across the columns.” The axis you name is the one that disappears from the result.

Broadcasting

So far we combined arrays of the same shape, or an array with a scalar. Broadcasting is the set of rules NumPy uses to combine arrays of different shapes. It is what makes the scalar case work, and it extends to more interesting cases.

Suppose we have average monthly revenue for several stores, and we want to subtract these values from monthly figures to center the data. The array revenue has shape (4, 3); the vector of store means has shape (4,).

store_means = revenue.mean(axis=1)
store_means
array([12.33333333, 21.        ,  9.33333333, 31.        ])

If we try to subtract directly, NumPy lines the shapes up from the right and the dimensions do not match:

revenue - store_means
---------------------------------------------------------------------------
ValueError                                Traceback (most recent call last)
Cell In[29], line 1
----> 1 revenue - store_means

ValueError: operands could not be broadcast together with shapes (4,3) (4,)

We need to make store_means a column, with shape (4, 1). The keepdims=True option does exactly this:

store_means = revenue.mean(axis=1, keepdims=True)
store_means.shape
(4, 1)
revenue - store_means
array([[-2.33333333, -0.33333333,  2.66666667],
       [-1.        , -3.        ,  4.        ],
       [-1.33333333, -0.33333333,  1.66666667],
       [-1.        , -3.        ,  4.        ]])

NumPy “stretches” the single column across all three months so the shapes line up.

Rules

  1. Compare the shapes of the two arrays starting from the rightmost dimension.
  2. Two dimensions are compatible if they are equal, or if one of them is 1.
  3. A dimension of size 1 is stretched to match the other array.
  4. If any pair of dimensions is incompatible, NumPy raises an error.
# (4, 3) with (3,): compatible, the vector is applied to every row
revenue - revenue.mean(axis=0)
array([[ -7.  ,  -4.75,  -6.5 ],
       [  3.  ,   1.25,   3.5 ],
       [ -9.  ,  -7.75, -10.5 ],
       [ 13.  ,  11.25,  13.5 ]])

Centering numerical data is very common in data analysis. We will see this operation many times throughout the quarter.

TipWhen in doubt, check .shape

Most broadcasting errors can be diagnosed by printing the .shape of both arrays and checking the rules above.

What about np.vectorize?

NumPy has a function called np.vectorize that converts an ordinary Python function into one that accepts arrays.

def tiered_discount(amount):
    if amount > 250:
        return 0.10
    elif amount > 100:
        return 0.05
    else:
        return 0.0

discount = np.vectorize(tiered_discount)
discount(sales)
array([0.05, 0.  , 0.05, 0.05, 0.  , 0.1 ])

This is convenient, but be careful: np.vectorize is just a loop in disguise and does not give you the speed benefit. It is fine for small data or quick prototyping, but prefer true vectorized operations such as np.where when performance matters. For several conditions, np.select is a good option:

conditions = [sales > 250, sales > 100]
choices = [0.10, 0.05]
np.select(conditions, choices, default=0.0)
array([0.05, 0.  , 0.05, 0.05, 0.  , 0.1 ])

Exercises

  1. A retailer sells four products with prices [19.99, 5.49, 102.00, 45.50] and the quantities sold last month were [30, 120, 8, 22].

    1. Compute the revenue for each product.
    2. Compute total revenue.
    3. Which product(s) contributed more than 25% of total revenue? (Use a mask.)

  2. Create an array of one million random numbers with np.random.rand(1_000_000). Compute the sum of their squares two ways: using a for loop, and using a vectorized expression. Compare the time taken.

  3. Given scores = np.array([55, 72, 88, 91, 40, 67, 79]), use np.where to produce an array with "pass" for scores of 60 or higher, and "fail" otherwise. What fraction of students passed?

  4. A 2D array sales has shape (5, 4): five regions by four quarters.

    1. Compute the total for each region and the total for each quarter.
    2. Express each value as a percentage of its region’s total. (Hint: you will need keepdims=True.)

  5. Standardize a vector x by subtracting its mean and dividing by its standard deviation. Check that the result has mean (approximately) 0 and standard deviation 1.
